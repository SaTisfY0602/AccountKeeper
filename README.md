# AccountKeeper

一个简单的安卓本地记账应用，用来统一查看支付宝、微信和银行卡支出。

## 规划复盘

原规划里最合理的部分是把“发生平台”和“实际资金账户”拆开。比如微信付款但银行卡扣款时，平台是微信，实际账户是银行卡，这样才能解释真实资金流。

原规划的缺陷：

- 第一版直接上 Room、WorkManager、自动导入，启动成本偏高。
- 自动读取微信、支付宝和银行卡流水会碰到权限、隐私和平台限制，不适合作为 MVP 的前置条件。
- 如果过早自动合并重复记录，容易把真实的两笔相同金额消费误合并。

改进后的第一版：

- 先做本地可用账本，数据保存在手机本地。
- 支持手动记账、账户管理、流水查看、CSV 粘贴导入。
- 对“微信/支付宝记录 + 银行卡扣款记录”只提示疑似重复，由用户点击合并。
- 合并后原始记录仍保留，但银行卡扣款副本不再计入统计。

后续再升级：

- 把当前 JSON 本地存储迁移到 Room。
- 增加微信、支付宝、银行卡账单文件解析器。
- 增加导出、备份和恢复。
- 加入更细的重复识别规则和批量确认。

## 当前功能

- 首页显示本月收入、本月支出、账户概况、分类统计。
- 流水页支持按平台筛选。
- 记一笔支持选择发生平台、实际账户和分类。
- 账户页可以添加微信零钱、支付宝余额、银行卡、信用卡、现金。
- 导入页支持粘贴 CSV。
- 首页会展示疑似重复流水，并可合并为同一笔支出。

## 长期方向

长期规划见 [docs/project-plan.md](docs/project-plan.md)。

项目会逐步从简单记账升级为本地优先的自动省钱管家：通知/短信识别收支、自动去重、自动分类、预算额度滚入、超额提醒和月底对账都会围绕统一的数据管线实现。

技术栈和版本号见 [tech.md](tech.md)。

## CSV 格式

每行一笔：

```csv
时间,金额,平台,实际账户,分类,商户,备注
2026-09-03 12:31,-35.00,微信,默认银行卡,餐饮,午餐,微信支付但银行卡扣款
2026-09-03 12:31,-35.00,银行卡,默认银行卡,餐饮,财付通支付,银行卡流水
```

金额为负数表示支出，正数表示收入。

## 运行方式

用 Android Studio 打开本目录，等待 Gradle 同步后运行 `app`。

当前工程使用：

- Kotlin
- Jetpack Compose
- Material 3
- SharedPreferences + JSON 本地存储
- `compileSdk 36` / `targetSdk 36`，适配 Android 16 / OriginOS 6
- `minSdk 23`，覆盖 Android 6.0 及以上设备
- Java 17 toolchain，并开启 core library desugaring 以兼容旧系统上的 `java.time`

如果要在命令行构建，需要本机安装 Android SDK 和 Gradle，或者后续补充 Gradle Wrapper。
